    🔔 부스 호출 버튼

    게임이 무엇이든 상관없어요. 노트북마다 호출 버튼 창을 하나씩 띄워 두면, 누르는 순간 부원 휴대폰과 현황판에 알림이 가요.

    이 노트북 참가하기

    대표 노트북에서 받은 채널 이름을 넣고 이 노트북의 번호를 고르세요.

    아래 배치도에서 이 노트북 자리를 눌러도 돼요.

    처음 설정하기 (대표 노트북 한 대에서만)

    다른 노트북에서 여기를 새로 설정하면 채널이 달라져서 서로 호출이 안 가요. 채널 이름을 받았다면 위의 참가하기를 쓰세요.

    1. 채널 이름

    우리 동아리만 쓰는 비밀 이름이에요. 이 이름을 아는 사람은 누구나 알림을 보낼 수 있으니 자동으로 만든 이름을 그대로 쓰는 걸 추천해요.

    2. 노트북 이름 (한 줄에 하나)

    3. 노트북마다 열 주소

    각 노트북에서 자기 주소를 열어 두세요. 게임을 전체 화면으로 할 때는 그 창에서 📌 게임 위에 작게 띄우기를 누르면 호출 버튼이 항상 위에 떠 있어요.

    주소 대신 공통 참가 주소 하나만 나눠 줘도 돼요. 열면 채널 이름이 미리 채워져 있어서 번호만 고르면 돼요.

    작은 창 위의 주소 줄이 거슬리면 윈도우 프로그램(BoothCall.exe)을 쓰세요. 주소 줄 없이 버튼만 떠 있고, 눌러도 게임 창 포커스를 뺏지 않아요. 처음 실행할 때 위 참가 주소를 붙여넣으면 끝이에요.

    4. 부원이 알림 받기

    1. 휴대폰: ntfy 앱 설치(안드로이드 Play 스토어 / 아이폰 App Store에서 “ntfy”) → + → 채널 이름 입력 → 구독.
      알림에 있는 [내가 갈게]를 누르면 노트북 화면에 “부원이 오고 있어요”가 떠요.
    2. 현황판(부스 노트북이나 태블릿): 아래 주소를 열고 “알림 소리 켜기”를 누르세요.
