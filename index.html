    🔔 부스 호출 버튼 만들기

    게임이 무엇이든 상관없어요. 노트북마다 호출 버튼 창을 하나씩 띄워 두면, 누르는 순간 부원 휴대폰과 현황판에 알림이 가요.

    1. 채널 이름

    우리 동아리만 쓰는 비밀 이름이에요. 이 이름을 아는 사람은 누구나 알림을 보낼 수 있으니 자동으로 만든 이름을 그대로 쓰는 걸 추천해요.

    2. 노트북 이름 (한 줄에 하나)

    3. 노트북마다 열 주소

    각 노트북에서 자기 주소를 열어 두세요. 게임을 전체 화면으로 할 때는 그 창에서 📌 게임 위에 작게 띄우기를 누르면 호출 버튼이 항상 위에 떠 있어요.

    4. 부원이 알림 받기

    1. 휴대폰: ntfy 앱 설치(안드로이드 Play 스토어 / 아이폰 App Store에서 “ntfy”) → + → 채널 이름 입력 → 구독.
      알림에 있는 [내가 갈게]를 누르면 노트북 화면에 “부원이 오고 있어요”가 떠요.
    2. 현황판(부스 노트북이나 태블릿): 아래 주소를 열고 “알림 소리 켜기”를 누르세요.
