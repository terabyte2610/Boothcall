# 부스 호출 버튼

동아리 부스에서 노트북마다 띄워 두고, 누르면 부원을 부르는 버튼. 게임이 무엇이든(Unity, 링크 배포 게임 등) 상관없이 옆에 같이 쓴다.

- **주소:** https://vecar0.github.io/terabyte/
- 파일 하나(`index.html`)로 끝. 서버·빌드 없음. 알림 중계는 [ntfy.sh](https://ntfy.sh)(무료, 가입 없음).

## 쓰는 법

1. **대표 노트북 한 대**에서 위 주소를 열고 "처음 설정하기"에서 채널 이름(자동 생성)을 확인한다. **📋 주소 전부 복사**로 채널 이름과 주소를 카톡/구글 문서에 붙여 둔다.
2. **나머지 노트북**: 위 주소를 열고 **이 노트북 참가하기**에 채널 이름과 번호(이름은 선택)를 넣고 **🔔 호출 버튼으로 참가**. 공통 참가 주소(`?t=채널`)로 열면 채널 이름이 이미 채워져 있어 번호만 고르면 된다. 한 번 참가하면 그 노트북은 다음에 기본 주소만 열어도 지난 정보가 채워져 있다.
3. 호출 버튼 화면에서 **📌 게임 위에 작게 띄우기** → 화면 맨 위에 항상 떠 있는 작은 호출 버튼. 그다음 게임 실행(크롬/엣지).
4. **부원 노트북(현황판)**: 참가하기에서 **📣 현황판으로 참가** → **🔊 알림 소리 켜기**를 한 번 누른다. 호출이 오면 소리 + 빨간 카드, **[내가 갈게]**를 누르면 게임 노트북에 "부원이 오고 있어요"가 뜬다.
5. (선택) **휴대폰**: ntfy 앱에서 같은 채널 이름을 구독하면 알림이 오고, 알림의 [내가 갈게]로 응답할 수 있다.

## 윈도우 프로그램 (주소 줄 없는 버전)

웹의 작은 창은 크롬이 위에 사이트 주소 줄을 붙인다(보안상 없앨 수 없음). 주소 줄 없이 버튼만 띄우려면 **[BoothCall.exe](https://github.com/vecar0/terabyte/releases/download/app/BoothCall.exe)** (윈도우 10/11, 설치 없음).

- 처음 실행하면 채널 이름을 묻는다 → 참가 링크를 통째로 붙여넣으면 채널·번호·이름이 채워진다.
- 왼쪽 클릭 = 호출, 끌기 = 옮기기, 오른쪽 아래 모서리 끌기 = 크기, 오른쪽 클릭 = 메뉴(호출 취소 · 설정 · 크기 · 종료).
- 눌러도 게임 창의 포커스를 뺏지 않는다. 작업 표시줄에는 안 보인다(끄려면 오른쪽 클릭 → 종료).
- 서명 안 된 프로그램이라 처음에 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
- 웹 버전과 같은 채널·메시지라 현황판·휴대폰·웹 버튼과 섞어 쓸 수 있다.
- 코드: `windows/BoothCall.cs`. `windows/` 아래를 main에 푸시하면 GitHub Actions가 윈도우에서 빌드·자체 시험 후 릴리스 `app`에 올린다.

## 주의

- 호출 페이지 탭을 닫으면 작은 창도 닫힌다. 노트북을 다시 켜면 📌를 다시 눌러야 한다.
- Unity 게임을 "독점 전체 화면"으로 실행하면 작은 창이 가려질 수 있다 → 창 모드 전체 화면(기본값)이나 `-screen-fullscreen 0`으로 실행.
- 노트북마다 "처음 설정하기"를 따로 하면 채널이 달라져 서로 호출이 안 간다. 대표 노트북 한 대만 설정하고 나머지는 참가하기.
- 채널 이름을 아는 사람은 누구나 알림을 보낼 수 있으니 자동 생성된 이름을 쓴다.
- ntfy.sh 무료 사용량 제한이 있다(같은 인터넷 주소를 쓰는 노트북끼리 나눠 씀). 부스 규모에서는 보통 문제없다.

## 배포 (처음 한 번)

저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 저장하면 1~2분 뒤 위 주소로 열린다.
